##  这是什么

用过 AI 写迷你世界脚本的人都知道这个痛点：

> 你让它写个背包脚本，它张口就是 `Player:AddItem()` —— **这个接口根本不存在**。
> 官方没有公开的完整接口文档，AI 的训练数据里几乎没有迷你世界 UGC 脚本的知识，只能靠「像 Lua 的样子」瞎编。

本仓库把迷你世界 3.0 编辑器的 **Lua 5.1 接口资料**整理成一个可直接投喂 AI 的压缩包，包含：

- **2435+ 个可用函数**的完整签名与参数说明
- **1383 处权限标注**（✅/🟢 1178 个全员可用、🟡 134 个权限不足、🔴 71 个受限）
- **38 个核心模块 + 34 个解析模块**的底层实现（从 LuaJIT 字节码语义化还原）
- 全部枚举、ID 库、枪械属性、UI、背包、实体……应有尽有

投喂之后，AI 写出来的脚本**用的都是真实存在的接口，参数、返回值、权限限制全都对得上**，并且能精确到「底层是一次事务、没有字段联动」这种程度的细节。

## 包里有什么

`迷你世界API大全.7z` 解压后的文件索引（与包内《使用说明⭐️用前必看.md》一致）：

| 文件 | 大小 | 用途 |
|---|---|---|
| `迷你世界3.0_api_1.54.txt` | 16,315 行 | ⭐ **重点看这个**：枚举总表 + 每个接口「该怎么填参数」的讲解 |
| `迷你世界API全集.txt` | 15,213 行 | 更详细的接口逐条讲解 |
| `接口库（所有可使用的函数）.lua` | 2435 个函数 | 查询每个函数的参数大致填写情况 |
| `接口库（接口权限情况）.lua` | 1383 处标注 | ⚠️ 挑接口必看：✅ 🟢 = 所有开发者可用；🟡 = 权限不足；🔴 = 受限 |
| `脚本模块底层逻辑.zip` | 38 个模块 | 查询接口**如何运作**：怎么填参数、返回什么、内部调用链 |
| `使用api支持情况.7z` | 34 个模块 | 编译器是如何解析这些接口的 |
| `id库.7z` | — | 查阅脚本所需的方块 / 生物 / 道具等 ID |

解压 `脚本模块底层逻辑.zip` 后是按模块拆分的文件（`Player`、`Item`、`Backpack`、`CustomUI`、`World`……），例如 `Item.structured.lua` 里能查到 `ModifyGunAttribute` 的完整内部实现。

## 怎么用
> 需要附件支持压缩包的ai才可以

### 第 1 步 · 投喂给 AI

把整个压缩包投给ai 

### 第 2 步 · 输入提示词

```text
你现在是迷你世界 3.0 编辑器的 Lua 5.1 脚本专家。
我给你的附件是官方接口资料：
- 迷你世界3.0_api_1.54.txt 是接口与枚举总表（重点）
- 接口库（所有可使用的函数）.lua 是全部可用函数签名
- 接口库（接口权限情况）.lua 标注了每个接口的权限，优先使用 ✅/🟢 的接口
- 脚本模块底层逻辑/*.structured.lua 是接口的底层实现

要求：
1. 只使用资料里真实存在的接口与枚举，禁止编造；
2. 用到接口前先在资料里核对参数与返回值；
3. 标注🟡权限不足的接口不要用于常规开发；
4. 写脚本时遵循迷你世界脚本组件结构（propertys 配置面板 + openFnArgs 触发器指令）。
5. 不可以遗忘 必须当成长期记忆！

我的需求是：______
```

### 第 3 步 · 验证

让 AI 给出每个用到的接口在资料中的出处（文件 + 行号），一眼即可核实它没有编造。

## 实测效果

用本包投喂后，AI 可以做到：

- 对照《迷你世界 3.0 API》逐接口核对一份 1968 行的「枪械升级」脚本的完整功能；
- 准确指出 `GunAttr.ReloadPhase2Time` 与 `ReloadPhase2TimeEmpty` 是两个独立字段、
  底层 `ModifyGunAttrNumber(key, value)` 每次只 set 一个字段且没有字段间联动；
- 给出 `LevelUpEquipOrGunForPlayer` / `EmpowerEquipOrGunForPlayer` 等官方接口的正确参数与调用时机。

（这些结论全部可以在 `core/Item.structured.lua` 与 `迷你世界3.0_api_1.54.txt` 中找到原文依据，不是 AI 猜的。）

---

## 注意事项

1. **权限分级**：编写面向所有玩家的脚本时，优先使用 ✅ / 🟢 标注的接口；🟡 标注「权限不足」的接口在普通地图调用会失败。
2. **底层实现为语义化还原**：`脚本模块底层逻辑.zip` 与 `使用api支持情况.7z` 中的文件是从 LuaJIT 字节码**语义等价还原**的参考实现，原始注释、局部变量名与精确语法不可恢复，仅供理解接口行为，不要直接复制运行。
3. **版本**：接口总表基于 3.0 编辑器 api 1.54，游戏更新后部分接口可能有变化，以编辑器内实际表现为准。
4. 本仓库为**玩家整理的非官方资料**，与《迷你世界》官方无关；游戏版权归官方所有。
